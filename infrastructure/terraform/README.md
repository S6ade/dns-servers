# Infrastructure as Code (IaC) для DNS-серверов

Проект по автоматизации развертывания инфраструктуры в Yandex Cloud для учебной лаборатории по настройке DNS-серверов (Bind9 и Unbound).

## 📋 Описание проекта

Цель — создать воспроизводимую инфраструктуру, которая поднимается одной командой и настраивается через Ansible, без ручного кликания в консоли.

**Что делает проект:**
- Разворачивает сеть VPC и подсети в Yandex Cloud.
- Создает 3 виртуальные машины (Ubuntu 22.04 LTS).
- Настраивает группы безопасности (SSH, HTTP, DNS).
- Выводит публичные IP-адреса для дальнейшей настройки.

## 🏗️ Архитектура

Инфраструктура состоит из трех машин:
1.  **`bind-vm`** — сервер для авторитетного DNS (Bind9).
2.  **`unbound-vm`** — сервер для кэширующего DNS (Unbound).
3.  **`client-vm`** — клиентская машина для проверки работы DNS.

## ⚙️ Требования

Перед началом работы убедись, что у тебя установлено:
- **Terraform** (версия >= 1.0)
- **Yandex Cloud CLI** (для аутентификации)
- **SSH-ключ** (`~/.ssh/id_ed25519.pub`)

## 🔐 Аутентификация

В проекте используется **сервисный аккаунт** Yandex Cloud.
1. Создай сервисный аккаунт в консоли (или через CLI).
2. Сгенерируй ключ авторизации и сохрани его в файл `key.json` в папке `terraform/`.
3. Убедись, что файл `key.json` добавлен в `.gitignore` (никогда не коммить его в Git!).

## 🚀 Быстрый старт

### 1. Настройка переменных

Скопируй пример конфигурации и заполни своими данными:
```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars
```

Открой terraform.tfvars и укажи:
```bash
cloud_id и folder_id (можно получить командой yc config list).

ssh_public_key (содержимое файла ~/.ssh/id_ed25519.pub).

vm_image_id (ID образа Ubuntu 22.04, актуальный для твоего облака).
```

### 2. Запуск инфраструктуры
Выполни инициализацию и применение:
```bash
bash
terraform init
terraform apply
После подтверждения (yes) Terraform создаст сеть, подсети, группу безопасности и три виртуальные машины.
```

### 3. Получение IP-адресов
После успешного завершения Terraform выведет публичные IP-адреса:


- bind_vm_ip    = "x.x.x.x"
- unbound_vm_ip = "y.y.y.y"
- client_vm_ip  = "z.z.z.z"
Сохрани их, они понадобятся для настройки Ansible.

⚠️ Важные нюансы и ограничения
В процессе разработки возможно столкнуться с рядом ограничений Yandex Cloud, которые учтены в коде:

1. Лимиты квот: На новых аккаунтах действуют жесткие лимиты на количество vCPU и объем дисков. Если apply падает с ошибкой Quota limit, уменьши размер дисков (size) или количество ядер (cores) в main.tf.

2. Проблемы с зонами доступности: В некоторых зонах (например, ru-central1-a или ru-central1-e) могут наблюдаться сбои в работе сети или cloud-init. Если SSH не подключается, а VM в статусе Running, попробуй пересоздать машину в зоне ru-central1-d.

3. Блокировка state: Если Terraform упал и оставил блокировку, используй terraform force-unlock <ID> или перезапусти WSL.
